Koneksi Portal Monev Kemnaker

Target portal: monev.maganghub.kemnaker.go.id/dashboard/peserta

Opsi 1: Otomasi Login (Puppeteer + Chrome)

Sistem akan membuka browser lokal, masuk ke SSO Kemnaker (account.kemnaker.go.id), dan mengumpulkan sesi login MagangHub secara otomatis.

Tip: Jangan centang jika Kemnaker meminta verifikasi CAPTCHA atau OTP, agar Anda bisa menyelesaikannya di layar.

Opsi 2: Input Bearer Token Langsung

Jika Anda sudah login di browser kantor, salin Token dari DevTools (Network tab -> monev-api.maganghub.kemnaker.go.id -> Header Authorization: Bearer ...).

Token ini digunakan langsung untuk memanggil API presensi tanpa membuka browser.

Pengaturan WhatsApp Gateway & Template Notifikasi

Atur penyedia layanan pengiriman pesan WhatsApp dan sesuaikan format pengingat untuk anak magang.

Mode Simulasi memungkinkan Anda menguji pengiriman dan menggunakan tombol "Chat WA" langsung tanpa kuota API berbayar.
Jam ini akan dicantumkan di dalam pesan pengingat kepada anak magang.

Pengaturan Jadwal Otomatis (Cron Job)

Sistem akan mengecek absensi Kemnaker dan mengirim pengingat secara terjadwal di latar belakang.

Disarankan diatur 30 - 60 menit sebelum batas jam masuk pemagangan (misal pukul 09:00 WIB).
Pengingat hanya akan berjalan pada hari-hari yang dicentang.
